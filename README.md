# 微信小游戏：肉鸽飞机大战

Roguelike 竖屏弹幕射击，运行于**微信小游戏**。触摸拖拽机体、自动开火，拾取经验与道具成长，三波推进后与 Boss 交战；目前包含星空、沙漠、海洋、草原四张地图。

## 玩法循环

1. **主菜单**：选择机体（部分需金币解锁）、升级局外天赋、调整音乐；左上角显示金币存档。
2. **战斗**：拖拽移动，自动射击；拾取经验球升级、拾取道具（血/炸弹/磁吸/金币等）。
3. **成长**：拾取经验达阈值后出现升级面板（默认三条进化，可消耗免费或付费金币重掷）。当**已无可用进化**时，面板固定变为二选一：**恢复 50% 最大生命**或 **+500 本局金币**。
4. **波次**：共 **三波**。从本局开打起算，约 **第 60 秒** 进入第二波（精英更多），约 **第 90 秒** 进入 Boss 阶段；与玩家等级无关。打开升级面板时游戏时间不走动，波次时点相应顺延。
5. **第三波 Boss**：按地图选择主 Boss：星空在红 / 蓝之间随机，沙漠为旱魃，海洋为归墟·利维坦，草原为苍岚鹿王。**满血击败星空红 / 蓝 Boss** 后进入 **虚空（隐藏 Boss）** 战斗，击倒其二阶段本体后胜利；旱魃、利维坦与苍岚鹿王击败后直接结算。Boss 招式由独立 AI 脚本驱动。
6. **结算**：阵亡或通关后写入金币与最佳记录（经验型成长与局外天赋跨局保留）。

## 可选角色 (`characters.js`)

| 机体 | 特点（摘要） |
|------|----------------|
| 破袭者 | 默认解锁，数值均衡 |
| 重炮手 | 更高单发伤害、较低生命 |
| 侦察兵 | 更快射速，初始三向弹道 |
| 守望者 | 高生命，**主炮子弹默认可穿透敌机**，带持续回血 |
| 机械师 | **2** 颗轨道卫星；卫星射出伤害略低的追踪弹 |
| 吸血鬼 | 自带吸血比例加成 |
| 潮汐使 | **通关海洋解锁**；初始获得最大生命 20% 的护盾，每 4 轮主炮追加两枚追踪潮弹 |
| 逐风者 | **通关草原解锁**；累计实际移动 180 像素后，下一轮主炮伤害 ×1.8，并穿透敌人 |

穿透效果与局内词条 **「穿透核心」** 一致：击中敌机后主炮子弹可持续飞行直至出屏（卫星弹等仍为单次命中）。

## 地图（`maps.js`）

主菜单里**天赋栏横向滑动**即可切到地图选择页（上方角色选择不受影响，其余布局不变）；页码圆点在「天赋 / 地图」标题右侧。选择会记进存档，下次进菜单默认选中。

| 地图 | 说明 | 解锁 |
|------|------|------|
| **星空** | 默认战场。深空星云，纵向下坠的星点，随波次在深蓝→紫→绿→红之间推进 | 默认可用 |
| **沙漠** | 风沙战场。横向吹拂的沙粒，随波次在暮色沙丘→黄沙→赤色沙暴→夜漠之间推进 | **击败隐藏 Boss（虚空线）后解锁**；解锁前不出现在列表里 |
| **海洋** | 珊瑚浅海→暮蓝深水→归墟海沟。交替横流、5 种海洋敌兵、深渊灯鮟精英与双阶段 Boss「归墟·利维坦」 | 默认可用；旧存档自动兼容 |
| **草原** | 苍岚草海、周期侧风，5 种草原敌兵、雷角野牛精英与双阶段 Boss「苍岚鹿王」 | **仅通关海洋后解锁**；未解锁时显示条件 |

**通关解锁链**：海洋胜利同时解锁草原与潮汐使；草原胜利解锁逐风者。星空隐藏虚空线胜利仍解锁沙漠。地图与角色奖励永久保存，重复通关不会重复领取解锁奖励。

地图是一张**注册表**：用 id 组合已注册的内容（`enemyPool` 刷怪池 / `eliteType` 精英 / `bossVariant` Boss / `mechanics` 玩法机制 / `themes` 色带 / `loot` 掉落规则）。`battle.js` 与 `menu.js` 读取配置，专属敌人行为、视觉与机制由对应模块接入。

**加一张新地图**：在 `enemies.js` 登记刷怪池/精英/Boss、`mechanics.js` 登记新机制、`maps.js` 串联配置、`storage.js` 补默认解锁值；新增视觉与战斗效果时接入对应模块。`validateMaps()` 校验内容引用，避免错误 id 静默回落到默认内容。

沙漠有 **8 条地图专属海克斯**（逆风者 / 拾荒者 / 沙镜 / 风蚀 / 热寂 / 流沙缚 / 沙暴之眼 / 旱魃之息）；海洋另有 **8 条专属海克斯**，围绕涨潮爆发、经验收集与潮汐生存构筑；草原有 **6 条专属海克斯**（顺风快射 / 风播种子 / 盘根护甲 / 风息回春 / 草原猎手 / 苍岚风暴）。`upgrades.js` 中 `entry()` 的 `options.maps` 控制地图限制，不填就是全地图通用。

海洋每轮为 **14 秒平潮 → 2.2 秒预警 → 8 秒涨潮**，退潮时横流换向。涨潮期间拾取经验 **+20%**，潮汐在 Boss 战继续运行；击败利维坦直接通关。敌群行为、Boss 招式、完整海克斯数值、浏览器预览与验证方式见 [海洋地图设计与实现](docs/ocean-map.md)。

草原每轮为 **16 秒静风 → 2 秒预警 → 7 秒侧风**，每轮退风换向。侧风以每秒 **18 像素**推动机体，拾取经验 **+15%**；盘根护甲可免疫推动，其他专属海克斯强化侧风火力、经验或退风治疗。苍岚鹿王半血进入二阶段，使用提前预警的鹿角分流、向外扩散的环蹄震波和保留至少 **108 像素**缺口的风径弹幕；击败后直接结算 **1200 金币**。机制在 Boss 战继续，升级选择期间暂停。详见 [草原地图设计与实现](docs/grassland-map.md)。

## 局内进化（`upgrades.js`）

大量唯一词条随机出现，稀有度分级（绿/蓝/紫/橙），每条每局仅能获取一次（部分有前置解锁，少数可重复）。**部分词条限定地图**（`options.maps`），例如草原的 6 条专属海克斯只在草原出现。包括但不限于：射速、弹体大小与速度、多向弹幕、暴击与吸血、护盾与对精英/Boss 增伤、清屏弹幕概率、弹道摧毁敌弹（「无坚不摧」）、轨道卫星与分叉升级等。**穿透核心** 为单条效果，已不再存在 II/III 升级链。

## 局外天赋（`talents.js`，永久）

- **体魄**：起始最大生命 +10%/级  
- **火力**：起始子弹伤害 +3%/级  
- **敏捷**：射速 +5%/级  
- **智慧**：经验倍率叠乘  
- **幸运**：道具掉落率 +4%/级  
- **重掷**：每级 +1 次局内升级面板的免费重随机次数  
- **引力**：起始拾取范围（经验/道具磁吸圈）每层 **+15%**（在基础 40 像素上叠加，局内磁力词条仍加法叠加上去）  
- **诅咒**：每层使敌方生命、弹幕与撞击伤害提高 **5%**，且普通刷怪倒计时按同一系数加快 **5%**（更难、更压迫）  

各项有独立等级上限与金币花费曲线。天赋较多时菜单「天赋」区域可纵向滑动。

## 掉落与道具（`items.js`）

- **经验球**：小/中/大/巨型四档颜色与分值不同，主要来源为击杀掉落。  
- **红心 / 炸弹 / 磁吸 / 金币**：常规加权随机掉落。  
- **Boss 周期掉落**：可出现短时 **无敌（INV）** 及血/磁吸/炸弹/金币等道具。**直升一级（LV+）不再默认掉落**——需先拾取紫色词条 **「空投信标」**，此后本局剩余时间内战场会不定期空投升级包；或走 **「战术学习III」** 的按概率尸体掉落。

清屏命中类效果会触发近似炸弹的视觉闪光（含冷却，避免刷屏）；炸弹道具仍为清屏敌弹 + 全屏闪光等逻辑。

## 敌机（`enemies.js`）

多个普通型号与精英；Boss 包含多形态虚空与阶段机制，复杂行为在 **`bossAi.js`**（与其它敌人的简单移动/射击逻辑拆分）。

## 开发者调试（可选）

源码中 **`menu.js`** 打开 `DEV_ENABLED` 后，菜单右上角可出现 **DEV** 入口：可改起始等级/波次、Boss 变种、起手升级模式、金币与部分词条调试等。**发行前请按需关闭**，避免误入调试参数。

## 项目结构

```
wechat-roguelike-demo/
├── game.js                 # 入口：canvas、场景切换、触摸与主循环
├── game.json               # 小游戏配置
├── project.config.json     # 工程配置（小游戏）
├── src/
│   ├── config.js           # 画布尺寸、主题等常量
│   ├── storage.js          # 本地存档（金币/角色与地图解锁/天赋/选项）
│   ├── audio.js            # BGM / 音效开关
│   ├── talents.js          # 局外天赋定义与加成聚合
│   ├── characters.js       # 可玩机体
│   ├── maps.js             # 地图注册表（只组合下面这些，不写玩法逻辑）
│   ├── mechanics.js        # 玩法机制注册表（沙暴等）
│   ├── enemies.js          # 敌兵、精英与 Boss 数据工厂
│   ├── bossAi.js           # Boss（尤其虚空）复杂 AI 与部分场地效果
│   ├── upgrades.js         # 局内进化池与抽取逻辑
│   ├── items.js            # 掉落物类型与生成
│   ├── menu.js             # 主菜单 UI 与存档消费
│   └── battle.js           # 战斗：碰撞、波次、升级面板、胜负结算
└── README.md
```

## 运行

1. 安装并打开 **微信开发者工具**。  
2. **导入项目** → 目录选本文件夹 `wechat-roguelike-demo`。  
3. 项目类型选 **小游戏**。  
4. 编译运行。

若使用仓库内 `project.private.config.json` 等本地文件，注意不要将含隐私的私有配置提交到公开仓库。

# 草原 · 苍岚草海

通关海洋、击败利维坦后，同时解锁**草原地图**与海洋新角色**潮汐使**；随后通关草原、击败苍岚鹿王，解锁**逐风者**。奖励永久保存在原有存档中，保留金币、天赋和其他已解锁内容。草原在解锁前仍显示入口与条件；两个通关奖励角色均不通过金币购买。

草原以方向交替的侧风组织走位：无风时调整位置，预警时观察下一阵风的方向，起风时利用射速、经验与伤害增益。地面采用分层草叶、种子与远处树影，敌群以叶片、甲壳、花瓣、羽翼和鹿角形成不同轮廓。弹幕和预警保留清楚的明暗、色相区分。

## 三波旅程

| 阶段 | 时间 | 场景 | 战斗内容 |
|---|---|---|---|
| 第一波 | 0–60 秒 | 青绿草甸 | 先辨认弧线跳跃与锁定冲刺，熟悉侧风预警。 |
| 第二波 | 60–90 秒 | 金穗原野 | 甲虫和花类弹幕加入，雷角野牛精英出现。 |
| 第三波 | 90 秒起 | 苍岚林缘 | 深绿草海与掠风隼，迎战苍岚鹿王。 |

## 侧风与海克斯

每轮为**无风 16 秒 → 预警 2 秒 → 侧风 7 秒**。首轮向右，以每秒 **18 逻辑像素**横推机体；退风后换向。机体受屏幕边界约束，拖拽锚点随位移同步。Boss 战保留完整周期；升级选卡时战斗与侧风一起暂停。

侧风期间拾取的经验自带 **×1.15**，与经验类天赋和海克斯相乘。「风播种子」生效时合计 **×1.5525**；例如基础 100 点经验按倍率先得到 155.25，再遵循原有经验结算的取整规则。无风和预警阶段不提供临时增益。

六个专属海克斯仅在草原候选池出现，每局最多获得一次。

| 品质 | 名称 / id | 精确效果 |
|---|---|---|
| 绿 | 顺风快射 `grass_tailwind` | 侧风期间射速 **+25%**。 |
| 绿 | 风播种子 `grass_seed` | 侧风期间拾取经验 **+35%**，与地图倍率叠乘。 |
| 蓝 | 盘根护甲 `grass_roots` | **免疫侧风推动**；最大生命 **+15%**，获得时补充同等数值的生命。 |
| 蓝 | 风息回春 `grass_bloom` | 每次侧风结束，回复 **5% 最大生命**。 |
| 紫 | 草原猎手 `grass_hunter` | 对精英、Boss 的伤害倍率均 **×1.2**。 |
| 橙 | 苍岚风暴 `grass_gale` | 前置「顺风快射」；侧风期间全部伤害 **+35%**。 |

退风治疗由机制的一次性事件触发，同一帧重复读取不会重复治疗。生命回复和上限仍由战斗层的既有规则约束。侧风增伤应用于主炮、卫星、炸弹和反伤，与通用增伤共同结算。

## Boss：苍岚鹿王

`antlerKing` 在第三波登场，生命降至 **50%**进入二阶段。鹿角、胸口与蹄下的蓄力动作对应三类攻击；每次预警均为 **1.1 秒**。预警和发射期间本体与发射原点固定，最后齐射后可在上方移动，等待自身实际余弹离场再换招。击败后直接胜利，Boss 基础金币 **1200**，不连接隐藏虚空线。

| 招式 | 一阶段 | 二阶段 | 躲避方式 |
|---|---|---|---|
| 鹿角扇流 `antlerFan` | 每侧鹿角 3 路、共 2 轮 | 每侧鹿角 4 路、共 3 轮 | 观察两侧分叉扇区，移入射线间隙。 |
| 草印脉冲 `hoofStamp` | 锁定圆半径 76，12 发向外弹 | 半径 92，14 发向外弹 | 预警锁定位置，弹体由圆周向外扩散；圆心不直接造成伤害。 |
| 苍岚风廊 `galeCorridor` | 2 排弹墙 | 3 排弹墙 | 沿至少 **108 像素**宽的固定安全缺口通过。 |

## 两个通关奖励角色

海洋通关奖励**潮汐使**（`tidecaller`）：初始生命 **2800**，主炮伤害 **840**，射击间隔 **420 毫秒**。开局获得等于 **20% 最大生命**的护盾；每发射 **4 轮主炮**，追加 **2 发追踪潮弹**，每发基础伤害为当前主炮伤害的 **×1.4**。主炮轮数按一次齐射计数，额外弹道不会提前触发。

草原通关奖励**逐风者**（`windrunner`）：初始生命 **2600**，主炮伤害 **880**，射击间隔 **400 毫秒**。累计有效移动 **180 逻辑像素**后储存一次强化：下一轮主炮伤害 **×1.8**，并穿透敌人。一次仅储存一轮强化，消耗后重新积攒。蓄风进度与就绪状态在画面底部显示，鼓励连续走位与选择强化发射时机。

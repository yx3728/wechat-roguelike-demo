# 草原 · 苍岚草海

通关海洋、击败利维坦后，同时解锁**草原地图**与海洋新角色**潮汐使**；随后通关草原、击败苍岚鹿王，解锁**逐风者**。奖励永久保存在原有存档中，保留金币、天赋和其他已解锁内容。草原在解锁前仍显示入口与条件；两个通关奖励角色均不通过金币购买。

草原不靠"周期性全局增益"组织战斗——那是海洋潮汐的套路。这里的轴是**地形**：场上散布可藏身的草丛，敌人会主动利用它、破坏它、或往里种东西，玩家则在"进草丛隐蔽"与"出草丛输出"之间取舍。地面采用分层草叶、种子与远处树影，敌群以叶片、甲壳、花瓣、羽翼和鹿角形成不同轮廓。

> 设计沿革：早期方案是"方向交替的侧风"，与海洋潮汐机制雷同、敌人也只是换皮，已整体废弃。当前实现为下面的栖息地方案；`crosswind`、`grass_tailwind` 等旧标识符在代码里不存在。

## 三波旅程

| 阶段 | 时间 | 场景 | 战斗内容 |
|---|---|---|---|
| 第一波 | 0–60 秒 | 青绿草甸 | 先辨认弧线跳跃与藏身节奏，熟悉草丛的掩护与损耗。 |
| 第二波 | 60–90 秒 | 金穗原野 | 甲虫和花类弹幕加入，雷角野牛精英出现。 |
| 第三波 | 90 秒起 | 苍岚林缘 | 深绿草海与掠风隼，迎战苍岚鹿王。 |

## 栖息地机制（`grasslandHabitat`）

开局在固定五处生成草丛，相对坐标与半径为 `(0.18, 0.43, 31)`、`(0.76, 0.43, 34)`、`(0.46, 0.60, 28)`、`(0.18, 0.77, 33)`、`(0.81, 0.78, 36)`。

| 元素 | 规则 |
|---|---|
| **草丛掩体** | 玩家中心进入即隐蔽（`grassConcealed`）：敌人只能朝最后目击点行动。草丛按承受的敌弹计数损耗，破坏后 **14 秒**复原。 |
| **根芽** | 荆棘花与鹿王往地面种下，**650 毫秒**成熟；成熟后持续威胁，可被击毁。 |
| **藤蔓** | 缠住玩家造成拖拽减速，持续 **5 秒**。 |
| **兔子播种** | 疾草兔闪避后会在原地补种新草丛，战场地形随战斗推移而变化。 |

隐蔽不是无敌：站在草丛里会持续消耗它的耐久，草丛破了就暴露。所以"什么时候进、什么时候出"才是这张图的核心决策。

## 六个专属海克斯

仅在草原候选池出现，每局各自最多获得一次。

| 品质 | 名称 / id | 精确效果 |
|---|---|---|
| 蓝 | 密叶屏障 `grass_cover` | 所有草丛可多抵挡 **4 发**敌弹；现存草丛与兔子新种的草丛均生效。 |
| 绿 | 宿根复生 `grass_regrowth` | 被破坏的草丛恢复时间 **−40%**（14 秒 → 8.4 秒）。 |
| 紫 | 伏草一击 `grass_ambush` | 每次进入草丛后，藏身期间首轮主炮伤害 **+40%**。 |
| 蓝 | 斩芽回春 `grass_pruning` | 每击毁一枚敌方根芽，回复 **3% 最大生命**。 |
| 橙 | 庇护余韧 `grass_shelter` | 你所在的草丛被破坏时，获得 **5% 最大生命**的护盾。 |
| 蓝 | 断藤步 `grass_freestep` | 免疫藤蔓缠绕与拖拽减速。 |

六条全部围绕地形：要么让草丛更耐用，要么把"草丛被破坏"和"清根芽"转成收益。

## 草原生物

每种敌人的攻击前都有命名为 `warn` 的预警相——视觉层只按这个名字绘制预警圈，**预警期间本体不位移、锁定目标不变**。

| 名称 | 注册 id | 行为与应对 |
|---|---|---|
| 疾草兔 | `meadowHare` | 察觉来袭弹道后向侧方跳闪（**460 毫秒**），落地补种草丛；不主动攻击。 |
| 镰叶螳螂 | `bladeMantis` | 先躲进草丛潜伏，玩家靠近到 **240 像素**内才起手：预警 **950 毫秒**后沿弧线扑击；收招 **700 毫秒**内承伤 **×1.25**。 |
| 荧甲虫 | `lanternBeetle` | 飞到上方停住，预警 **1000 毫秒**后推出光球并缓慢下压 **600 毫秒**。 |
| 荆棘花 | `thornBloom` | 扎根后在玩家两侧种下根芽（**650 毫秒**成熟），冷却 **6.2 秒**。 |
| 掠风隼 | `galeFalcon` | 从屏幕侧面进入并环绕，预警 **650 毫秒**后俯冲，至多两次后离场。 |
| 雷角野牛（精英） | `thunderBison` | 护群姿态持续 **4.8 秒**，期间为同伴提供庇护；力竭 **1.8 秒**内承伤 **×1.6**。 |

## Boss：苍岚鹿王

`antlerKing` 在第三波登场，生命降至 **50%** 进入二阶段（转场硬直 **1.2 秒**）。它不是"随机抽招"：每次决策会读当前战场——玩家是否藏身、场上还剩几丛草——再给三个招式打分，冷却中的招式跳过。

| 招式 | 预警 | 冷却 | 内容与应对 |
|---|---|---|---|
| 犁地冲锋 `antlerPlow` | **1200 毫秒**（二阶段 1000） | 11 秒 | 沿一条画出的路线高速犁过，**沿途草丛被铲平**。玩家藏身时优先选它（评分 12），场上草多时次之。离开路线即可，但掩体会因此减少。 |
| 护群 `herdGuard` | 900 毫秒 | 15 秒 | 为存活的同伴拉出连线并加护，优先清小怪才能推进。 |
| 根园 `rootGarden` | 900 毫秒 | 15 秒 | 在多点同时种下根芽，把走位空间切碎；配合「斩芽回春」可反过来变成回血来源。 |

二阶段所有冷却 **×0.82**。击败后直接胜利，Boss 基础金币 **1200**，不连接隐藏虚空线。

## 两个通关奖励角色

海洋通关奖励**潮汐使**（`tidecaller`）：初始生命 **2800**，主炮伤害 **840**，射击间隔 **420 毫秒**。开局获得等于 **20% 最大生命**的护盾；每发射 **4 轮主炮**，追加 **2 发追踪潮弹**，每发基础伤害为当前主炮伤害的 **×1.4**。主炮轮数按一次齐射计数，额外弹道不会提前触发。

草原通关奖励**逐风者**（`windrunner`）：初始生命 **2600**，主炮伤害 **880**，射击间隔 **400 毫秒**。累计有效移动 **180 逻辑像素**后储存一次强化：下一轮主炮伤害 **×1.8**，并穿透敌人。一次仅储存一轮强化，消耗后重新积攒。蓄风进度与就绪状态在画面底部显示，鼓励连续走位与选择强化发射时机。

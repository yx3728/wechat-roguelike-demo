# 海洋 · 归墟远征

海洋地图把移动与成长连在同一个潮汐周期里：平潮时整理走位，预警时选择航道，涨潮时利用更高经验收益与海克斯爆发。地图默认解锁，旧存档保留金币、角色、天赋和已有地图选择；玩家可在主菜单的地图页选择海洋。

## 三波旅程

| 阶段 | 战斗时间 | 视觉主题 | 敌群变化 |
|---|---|---|---|
| 第一波 | 0–60 秒 | 珊瑚浅海：青绿海水、折射光纹、边缘珊瑚与上浮气泡 | 礁翼鳐、刺潮针鱼，先学习折返和锁定冲刺 |
| 第二波 | 60–90 秒 | 暮蓝深水：蓝色加深，中央保持清晰的弹幕通道 | 加入脉冲水母、堡礁蟹，以及深渊灯鮟精英 |
| 第三波 | 90 秒起 | 归墟海沟：深靛海床、低亮度远景与发光生物 | 加入墨潮乌贼，迎战「归墟·利维坦」 |

时间按实际战斗推进；三选一升级面板打开时，波次、敌人和潮汐一起暂停。海洋背景、敌人与 Boss 使用 Canvas 绘制，不依赖新增贴图加载。敌方危险弹幕使用暖珊瑚色与浅橙色；潮门航道、瞄准扇区、冲撞路径均有对应预警。

## 潮汐规则

每轮持续 24.2 秒：**平潮 14 秒 → 预警 2.2 秒 → 涨潮 8 秒**。涨潮以每秒 24 逻辑像素横推机体，首轮向右；退潮时换向，因此下一轮预警展示的就是下一次海流方向。机体受屏幕边界约束，拖拽锚点跟随海流移动。

涨潮期间拾取经验自带 **×1.2** 倍率。奖励在拾取时判定，可与智慧天赋、经验球价值和「潮汐拾荒」叠乘；例如原本 100 点经验，涨潮加拾荒为 180 点。进入 Boss 战不会中断潮汐，因此所有海洋海克斯仍可触发。

## 海洋敌群

| 敌人 | 注册 id | 行为与应对 |
|---|---|---|
| 礁翼鳐 | `reefRay` | 每 620 毫秒横向折返，中途短暂滑翔。提前占据其下一段下降路线。 |
| 刺潮针鱼 | `needlefish` | 下潜后锁定玩家方向，预警 720 毫秒，再沿锁定方向冲刺。预警期间横移。 |
| 脉冲水母 | `jellyfish` | 650 毫秒蓄力后释放八向疏环；齐射后冷却 2.7 秒。利用环形弹之间的空隙。 |
| 堡礁蟹 | `armoredCrab` | 合壳 1.8 秒时承伤 ×0.6；开壳停步 1 秒，承伤 ×1.35。集中火力打开放窗口。 |
| 墨潮乌贼 | `inkCuttlefish` | 锁定后预警 650 毫秒，连续三次三发扇射，每次间隔 230 毫秒，并向后喷退。避开初始瞄准方向。 |
| 深渊灯鮟（精英） | `abyssalAngler` | 850 毫秒蓄力（无场地预警标记），连续三轮双颚扇射，每轮 6 发，间隔 350 毫秒；中央留出安全扇区。收招后承伤 ×1.4；尾部轻摆，头部和灯饵稳定。 |

上述倍率是敌人自身的承伤窗口，会与已有对精英、Boss 伤害规则共同结算。专属射击行为取代战斗后期的通用补射，避免重复叠加弹幕。

## Boss：归墟·利维坦

利维坦在第三波出现，沿用分层血条和打破血条层后的硬直。击败后直接结算胜利与 1000 金币基础奖励；即使玩家满血，也不会接出隐藏虚空 Boss。

利维坦会在上方不同深度与横向航点间带惯性游动；最后一轮弹幕发完后即可换位，不必原地等待余弹离场。预警和实际发射期间位置锁定，冲刺在预警路径上加速、减速，结束后沿弧线返回。碰撞盒保持 120 × 120，侧倾、鳍翼摆动、尾鳍摇摆、甲片呼吸与张口蓄力均属于绘制动画。

潮门使用渐淡的危险海域与窄光带标示安全缺口；扇流用渐隐射线标示真实角度；冲刺使用轻薄航道、空心方向箭头与落点角标。场地不绘制招式名或“安全缺口”说明，依靠留白与线条引导。充能弧线显示出招进度，预警保留至少 900 毫秒。关闭闪光特效时停止装饰性身体动画，仍保留危险范围与蓄力姿态。

| 招式 | 一阶段 | 二阶段 | 预警与躲避 |
|---|---|---|---|
| 潮门 `tideGate` | 2 排横向弹墙，间隔 720 毫秒 | 3 排弹墙，间隔 580 毫秒 | 预警 1.1 秒；缺口在左、中、右航道轮换，宽度至少 108 逻辑像素。进入标出的缺口。 |
| 猎潮扇流 `abyssFan` | 3 轮、每轮 5 发 | 4 轮、每轮 7 发 | 预警 0.9 秒；每轮间隔 560 毫秒，始终朝预警开始时锁定的方向射击。离开瞄准线。 |
| 破渊冲撞 `breach` | 单次冲撞 | 连续两次冲撞 | 每次冲撞均有完整 0.9 秒路径预警；锁定后不追踪玩家，目标最深到屏高的 62%。向路径外移动。 |

一阶段按「潮门 → 扇流 → 冲撞」循环；生命降至 **50% 或以下**时，进入**至少 1.5 秒的停火与归位**，清除自身余弹，保留其他敌人的弹幕。二阶段按「潮门 → 冲撞 → 扇流 → 冲撞」循环，增加攻击次数而保留预警时间。

每个招式结束后提供 **1.4 秒、承伤 ×1.5** 的输出窗口。潮门与扇流均等待自身真实弹体离场，再衔接下一招；低帧率或时间流护盾减速时，也不会提前开始冲撞封住弹幕间隙。

## 八个专属海克斯

所有条目仅在海洋地图出现，每局最多获取一次；除「风暴潮」外均无前置要求。

| 稀有度 | 名称 / id | 效果 |
|---|---|---|
| 绿 | 涨潮快射 `ocean_rapid` | 涨潮期间射速 **+30%**。 |
| 绿 | 潮汐拾荒 `ocean_scavenger` | 涨潮期间拾取的经验 **+50%**，与地图自带 ×1.2 叠乘。 |
| 蓝 | 稳流鳍 `ocean_stable_fin` | **免疫海流推动**，主炮子弹速度永久 **+15%**。 |
| 蓝 | 退潮回生 `ocean_ebb_mend` | 每次涨潮结束，回复 **6% 最大生命**。 |
| 紫 | 珊瑚共鸣 `ocean_coral` | 涨潮期间全部伤害 **+25%**。 |
| 紫 | 深海猎手 `ocean_hunter` | 对精英和 Boss 的伤害倍率 **×1.25**。 |
| 橙 | 风暴潮 `ocean_storm_surge` | 前置「涨潮快射」；涨潮期间全部伤害 **+60%**，敌方子弹速度也 **+25%**。 |
| 橙 | 潮汐之心 `ocean_heart` | 每次涨潮开始清除全屏敌弹，补充 **20% 最大生命**的护盾，不超过护盾上限。 |

「珊瑚共鸣」和「风暴潮」按倍率叠乘，同时拥有时涨潮伤害为 **×2**；主炮、卫星碰撞、炸弹和反伤均接入潮汐增伤。「潮汐之心」建立至少等于 20% 最大生命的护盾容量，保留已有更大容量；获得词条后从下一次涨潮开始触发，最大生命增长后会更新最低容量。

## 预览与验证

在项目目录执行自动化测试：

```sh
node --test tests/*.test.js
```

77 项测试覆盖地图注册、加权刷怪、旧存档与旧地图兼容、海克斯门槛、潮汐与暂停、各伤害路径、利维坦预警和转阶段，以及主炮／卫星／炸弹击杀后的直接胜利与单次结算。视觉测试确认沙漠关闭贴图时不调用图片、动画不改碰撞盒、预警适配 320 / 390 / 768 宽度；另有 16 / 33 毫秒帧间隔及减速弹幕下的 Boss 连续运行测试。

贴图覆盖测试另行验证全部 8 个角色、24 类注册敌人及虚空分身、形态变化，以及卫星在同一局内随贴图开关正确切换。

启动浏览器预览：

```sh
node tools/preview.js
```

打开 [本地预览](http://127.0.0.1:4178)，可切换地图入口、海洋试玩、Boss 战与生物图鉴。预览读取真实战斗与绘制模块，浏览器存档独立于微信存档。微信端仍按 README 的小游戏导入步骤运行，用微信开发者工具与真机检查触控、画面和帧率。
